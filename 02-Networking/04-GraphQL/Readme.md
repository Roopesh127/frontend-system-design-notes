GraphQL :- created by facebook in 2012, after that open source it.

Why it's famous :- because of we don't need to create multiple request, in one single request we can access tha data, which we actually needed.

inside it we are creating, schema and inside it we define all thing which we actually needed. That's why we don't need to create multiple request.


# Benefits of GraphQL

1. Avoid Overfetching
2. Avoid Underfetching
3. Better Mobile performance (b/c mobile have limited or less memory)
4. Declarative data fetching (b/c we send schema)
5. Structured/Hierarchical Structure. (we  make us data Hierarchical based on our requirement, from client side)
6. Strongly typed
7. Introspection
